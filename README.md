# Smart Disaster & Fire Emergency Routing System
A custom C++ data-structure-oriented project designed to simulate emergency management and evacuation routing during natural disasters and fire emergencies.

## Project Overview
The system aims to identify safe evacuation routes, manage emergency resources, and prioritize rescue requests during critical situations.

It models a city's road network using a dynamic Graph and utilizes custom data structures to handle route optimization, emergency prioritization, and resource management.

All core data structures will be implemented from scratch in C++, without relying on STL containers such as `std::vector`, `std::map`, or `std::priority_queue`.

## Project Objectives

- Develop a custom data-structure-oriented system using C++.
- Calculate safe evacuation routes during disasters and fire emergencies.
- Prioritize emergency rescue requests based on severity.
- Analyze the time and space complexity of implemented data structures.
